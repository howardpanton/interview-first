# Tracker template

`job-search/tracker.csv` starts with this header row and nothing else. The skill's
"Columns" table says what each column holds.

```csv
date_found,company,role,type,location,work_pattern,office_days,salary_min,salary_max,day_rate,match_score,screener_score,priority,status,route,cv_version,date_applied,contact,next_action,next_action_date,listing_url,apply_url,notes
```
